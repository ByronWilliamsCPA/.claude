> **Status**: Proposed | Accepted | Deprecated | Superseded by ADR-NNN
>
> **Decision date**: YYYY-MM-DD
>
> **Deciders**: Byron Williams (or list)

## Context

What is the situation that prompted this decision? What forces are at play (technical, organizational, constraints)? Write this in a way that future-you can understand without re-reading the surrounding code.

## Decision

What did we decide? State it as a single declarative sentence: "We will X, because Y."

## Alternatives Considered

- **Alternative A**: What it was, why it was rejected.
- **Alternative B**: What it was, why it was rejected.

## Consequences

- **Positive**: What this decision enables or prevents.
- **Negative**: What this decision costs: and when that cost might become unacceptable.
- **Neutral**: What changes but isn't clearly good or bad.

## References

- Code files that embody this decision (with paths).
- Related ADRs (with numbers).
- External sources (with URLs).
