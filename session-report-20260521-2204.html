recommendations

Route general-purpose dispatches to typed subagents. general-purpose is the single largest subagent spend at 7.5% of total (163 calls, 1.3M avg). Replace with Explore for read-only codebase lookups, code-reviewer for review tasks, and research-agent for external research — each carries narrower context and costs roughly 40-60% less per call.
Batch compliance audits per session, not per repo. general-compliance-auditor (3M avg) and ossf-compliance-auditor (1.8M avg) are invoked one-per-repo via /repo-compliance. Grouping multiple repos into a single fleet audit session would amortize the system-prompt and tool-schema overhead that inflates each call.
Scope devops-deployment-agent prompts to specific files and targets. At 2M tokens/call (16 calls), the agent is loading broad infrastructure context per dispatch. Providing exact file paths, target host/container, and the specific change to apply can reduce context load by 30-50%.
Add /compact checkpoints to long cookiecutter-python-template sessions. 22 cache breaks in 15 sessions indicates sessions are regularly running past the 5-minute cache TTL. Calling /compact at natural task boundaries (after each major feature or PR) keeps context fresh and avoids full re-reads.
